Destiny Herbers' IRW Coding Assessment

Part 1 uses R packages diplyr, tidyverse, janitor and lubridate. There is code to install and library those packages included. The code should be ready to run, it is separated into small chunks with comments to describe each, and can be run as individual chunks or all at once. The analysis uses data from Juvenile_Arrests.csv in the data folder. 

I used Gemini to fix a syntax error on one line of code in Part 1, where I set the data to lowercase and squish extra whitespace. Other than that fix, I did not use AI tools on this assessment.
